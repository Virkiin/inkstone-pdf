Inkstone PDF 0.1.0 —— 手动安装说明
================================

一、装到哪里
------------
1. 打开你的 Obsidian 库文件夹（就是能看到 .obsidian 目录的那个文件夹）。
   如果看不到 .obsidian：Windows 资源管理器 → 查看 → 勾选「隐藏的项目」；
   macOS 在 Finder 里按 Cmd+Shift+. 显示隐藏文件。

2. 把压缩包里的 `inkstone-pdf` 整个文件夹，放到：
       <你的库>/.obsidian/plugins/inkstone-pdf/
   放好之后目录应该是这样：
       <你的库>/.obsidian/plugins/inkstone-pdf/main.js
       <你的库>/.obsidian/plugins/inkstone-pdf/manifest.json
       <你的库>/.obsidian/plugins/inkstone-pdf/styles.css

3. 重启 Obsidian（或按 Ctrl+R 重载）。

4. 设置 → 第三方插件 → 关闭「安全模式」（如果开着），然后「已安装插件」
   里刷新，找到 **PDF Ink**，打开开关。

二、怎么用（最少必要）
----------------------
- 打开任意 PDF 后，右上角会出现浮动工具栏；用数位笔直接在页面上写即可
  （鼠标默认不书写，避免影响选字；需要鼠标也能写时在设置里打开）。
- 工具：钢笔 P / 荧光笔 H / 橡皮 E / 选择 S / 直线 L / 箭头 A /
  矩形 R / 椭圆 O / 拖拽页面 G。所有键位都能在 设置 → 键位映射 里改。
- 双击或长按（或右键）笔刷按钮 → 笔刷面板（预设、调色板、粗细、不透明度）。
- **按住 F = 临时橡皮**，松开回到原来那支笔。想改成别的键：设置 → 键位映射
  →「按住 = 临时橡皮」。想把侧键当成"按住擦"，也可以在 键位映射里把「橡皮」
  那一行改成「按住生效」。
- **Shift + 笔贴着页面移动**：左右改粗细、上下改不透明度（悬停不生效，
  抬高笔即结束）。灵敏度在 设置 → 书写 →「Shift + 悬停调笔刷的灵敏度」。
- 选中笔迹后可拖动、四角/四边缩放、顶部圆点旋转，方向键微移（Shift = 10px）。
- 文字选择：选择工具 + 按住 Alt（鼠标和笔都可以）。
- 撤销 Ctrl+Z / 重做 Ctrl+Shift+Z。
- 笔迹保存在库内 `附件/Ink 标注/<PDF 相对路径>.json`，不修改原 PDF。

三、数位板推荐设置
------------------
- 设置 → PDF Ink → 输入方式 → 硬件 → 选 **数位板**：会关掉「停住笔尖」与
  「双击弹菜单」两组触屏手势（数位板上看不见笔尖停留，容易误触）。
- 把笔的侧键在驱动里映射成 **F**（或你自己的按住键），就是「按住擦、松开写」。
- 驱动里那种「切换笔刷」的内置功能我们收不到事件，别用它，改成映射键盘键。

四、环境要求
------------
- Obsidian 1.8.0 及以上，桌面版（Windows / macOS / Linux）。
- 数位笔压感需要浏览器能拿到 pen 事件（Wacom / 高漫 / 绘王 / XPPen 等一般都可以）。
- 书写发涩时：设置 → 书写 →「墨迹清晰度/流畅度」调到「流畅优先」或「极流畅」；
  「关闭其他插件的毛玻璃背景」保持开启（默认开，能显著减少卡顿）。

五、已知限制
------------
- 不支持在手机上使用。
- 旋转过的矩形/椭圆会被转换为等价多边形（外观一致，但不再是"形状"）。
- 侧车 JSON 体积会随批注量增长（几百条笔迹约 0.6–3 MB）。
- 旧版本（0.1.0-dev.20 及更早）保存的橡皮蒙版会在加载时被直接删除，被它们
  盖住的墨迹会重新显示——这是"直接删除"的预期行为。
